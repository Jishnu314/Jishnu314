[`View on GitHub`](https://github.com/jishnu314)

- Sends real-time alerts to the owner for unauthorized entry via messaging app

**Stack:** `ESP32 Cam` `C/C++`

---

### 👓 Smart Glasses for the Visually Impaired
[`View on GitHub`](https://github.com/jishnu314)

An AI-powered assistive wearable helping visually impaired users navigate, shop, and interact socially with greater independence.

- **Navigation** — Real-time obstacle detection with directional audio & haptic feedback
- **Vision AI** — Object ID, scene description & barcode scanning via on-device AI
- **Face Recognition** — Identifies known faces and speaks their name aloud; supports on-device enrollment
- **Fall Detection** — Detects falls, performs a consciousness check, sends SOS + live GPS to trusted contacts

**Stack:** `Python` `Raspberry Pi 4` `OpenCV` `YOLOv8` `MobileFaceNet` `MediaPipe` `TFLite` `Gemini API` `Firebase` `LiveKit`
