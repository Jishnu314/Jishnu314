I enjoy building things that bridge the physical and digital world — from PLC-controlled industrial systems to intelligent wearables that help people live more independently.

- 🔭 Currently working on **AI-powered assistive devices** and **edge AI deployment**

- 💬 Ask me about **Embedded Systems, PLC, Computer Vision**

## 🚀 Projects

### 👓 Smart Glasses for the Visually Impaired
[`GitHub ↗`](https://github.com/Jishnu314/Smart-Specs-For-Blind)

An AI-powered assistive wearable helping visually impaired users navigate, shop, and interact socially — with greater independence and dignity.

| Feature | Description |
|---|---|
| 🧭 Navigation | Real-time obstacle detection with directional audio & haptic feedback |
| 🔍 Vision AI | Object identification, scene description & barcode scanning via on-device AI |
| 🧑‍🤝‍🧑 Face Recognition | Identifies known faces and speaks their name aloud; supports on-device enrollment |
| 🚨 Fall Detection | Detects falls, performs a consciousness check, sends SOS + live GPS to trusted contacts |

**Stack:** `Python` `Raspberry Pi 4` `OpenCV` `YOLOv8` `MobileFaceNet` `MediaPipe` `TFLite` `Gemini API` `Firebase` `LiveKit`

### 🔔 Smart Doorbell with Face Recognition
[`GitHub ↗`](https://github.com/Jishnu314/Smart-Calling--Bell-IoT-project)

Keyless access control with real-time visitor alerts for unknown faces.

- Triggers face scan on button press; grants access to recognized users without a key
- Sends instant alerts to the owner for unauthorized entry via messaging app

**Stack:** `ESP32-CAM` `C/C++`
